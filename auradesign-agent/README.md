# Aura Designer Agent

**Aura Designer** — автономный программный комплекс для воссоздания веб-интерфейсов из любого источника (ссылка на живой сайт или изображение макета) на основе независимых дизайн-контрактов `AURADESIGN.md`.

Агент использует двухслойный подход к описанию интерфейсов: машиночитаемые токены YAML и высокоуровневые Markdown-инструкции для ИИ-верстальщика. Он независим от сторонних дизайн-брендов и глубоко интегрирован со сквозным циклом генерации безфоновой графики с помощью нейросетей.

---

## Основные возможности

1. **Сканирование стилей (`aura_scanner.py`):** Извлекает цветовую палитру, шрифты, логику контейнеров и размеры с любого живого URL-адреса или анализирует картинку-образец, переводя их в точный дизайн-контракт `AURADESIGN.md`.
2. **Дизайн-контракт (`AURADESIGN_SPEC.md`):** Фиксирует жесткие правила композиции для ИИ-верстальщика в едином документе-источнике правды. Полностью исключает использование смайликов и дешёвых эмодзи, навязывая использование чистых векторных SVGs.
3. **Модуль Ассетов (`aura_asset_manager.py`):** Координирует генерацию 3D-иллюстраций по теме сайта и предоставляет высококачественные безфоновые (прозрачные PNG) фоллбеки по нишам для стабильной автономной работы.
4. **Генератор Сайтов (`aura_generator.py`):** Превращает дизайн-контракт в чистую, интерактивную, адаптивную и готовую к публикации HTML-страницу с настроенным Tailwind-компилятором, шрифтовым ритмом, плавными анимациями и набором красивых кастомных inline SVGs под выбранную нишу.
5. **Единый CLI-Консоль (`aura.py`):** Управляет всеми модулями в одно касание или запускает автоматический сквозной конвейер. Очищен от эмодзи-выводов в консоль для 100% стабильности на любых ОС (включая Windows).

## Руководство по запуску

Инструмент написан на чистом Python 3 и **не требует сторонних библиотек** для парсинга и генерации. Для запуска достаточно установленного Python.

### 1. Импорт готового пресета ниши
Вы можете пропустить этап сканирования и развернуть один из премиальных стилей нашей библиотеки:
```bash
python aura.py preset saas
# или: fintech, glassmorphism, pets, cosmic, alpinism
```
*Файл спецификации будет записан в локальный `AURADESIGN.md`.*

### 2. Сканирование живого сайта
Запуск сканера для анализа любого интернет-ресурса (например, Linear или Stripe):
```bash
python aura.py scan --url https://linear.app --dark
```
*Интеллектуальный парсер выявит основные цвета, шрифты, замерит скругления и сформирует канонический `AURADESIGN.md` под стиль бренда.*

### 3. Генерация готового веб-интерфейса
Запуск сборки страницы по вашему текущему контракту `AURADESIGN.md`:
```bash
python aura.py generate --contract AURADESIGN.md --niche saas --output index.html
```
*Менеджер ассетов автоматически подберет графику, настроит ИИ-запрос на генерацию кастомного безфонового 3D-объекта, а генератор внедрит все дизайн-токены в структуру разметки.*

### 4. Сквозной автоматический конвейер (Pipeline)
Запуск полной цепочки в один шаг: сканирование -> построение контракта -> подбор безфоновой графики -> генерация готового сайта:
```bash
python aura.py pipeline --url https://weather-site.com --output index.html
```

## Интеграция с ИИ и удаление фонов

Агент использует двухэтапную связку инструментов для создания потрясающего визуала в Hero-блоках:
1. **Генерация:** По тексту контракта формируется ИИ-запрос на генерацию сложного 3D-объекта или иллюстрации.
2. **Очистка фона:** Полученный URL передается ИИ-модели `recraft/remove-background`, которая аккуратно вырезает объект, возвращая чистый PNG на прозрачном фоне.
3. **Размещение:** Генератор размещает прозрачный ассет поверх сложных фоновых градиентов или узоров сайта, позволяя ему парить с использованием CSS-анимаций.

*При запуске в среде ИИ-ассистента (например, Cursor), агент автоматически генерирует кастомные ассеты через MCP-инструменты `gpt-image-2` и `recraft_remove_background`.*
