# Aura Shape Replication

## Главный Закон

Шейп не выбирается из библиотеки любимых фигур агента. Шейп копируется из источника. Если пользователь прислал кляксы, делай кляксы. Если прислал кружки, делай кружки. Если прислал тонкие линии, не добавляй жирные рамки. Если прислал плоские формы без теней, не добавляй тени.

## Процесс Репликации Формы

1. Сначала опиши форму словами: круг, овал, капсула, прямоугольник, скругленный квадрат, blob, клякса, sunburst, цветок, лента, волна, рваная бумага, карточка, underline, divider.
2. Зафиксируй геометрию:
   - пропорции width/height;
   - радиус углов;
   - симметрия или асимметрия;
   - ровный контур или органический;
   - наличие stroke;
   - толщина stroke;
   - цвет stroke;
   - наличие тени, размытия, свечения;
   - наклон/rotation;
   - порядок слоев.
3. Выбери технику:
   - CSS `border-radius` для кругов, овалов, капсул, скругленных карточек;
   - inline SVG `path` для клякс, blobs, цветов, искр, лент, волн;
   - CSS pseudo-elements только если форма простая и не требует точного контура;
   - image asset через MCP KV, если форма является сложной иллюстрацией, текстурой, объектом или фото.
4. Повтори форму максимально близко. Не заменяй blob звездой, кляксу кругом, цветок ромбом, тонкую линию тяжелой обводкой.

## Каталог Форм и Как Их Делать

### Круги и Овалы

- Круг: `border-radius: 9999px`, `width == height`.
- Овал: `border-radius: 9999px`, `width != height`.
- Если в источнике нет stroke, не ставь border.
- Если круг мягкий пастельный, тень максимум `box-shadow: 0 8px 24px rgba(..., 0.08)`.

### Капсулы

- Используй `border-radius: 9999px`.
- Копируй ширину по тексту и padding источника.
- Если капсула наклонена, ставь точный `rotate(...)`.
- Не добавляй black outline, если его нет в источнике.

### Скругленные Квадраты и Карточки

- Копируй реальный радиус: 4px, 8px, 12px, 18px, 24px.
- Если карточка выглядит как бумага или стекло, используй фон/opacity/blur, а не бруталистскую рамку.
- Если карточка плоская, не добавляй shadow.

### Кляксы / Blobs / Органические Формы

- Делай inline SVG path с кривыми `C`/`S`/`Q`, а не polygon.
- Форма должна быть асимметричной, если источник асимметричен.
- Пример подхода: 8-12 опорных точек по контуру, между ними плавные cubic bezier.
- Допускается `clip-path: path(...)`, но inline SVG надежнее.

### Цветы / Лепестки

- Не заменяй цветок звездой.
- Используй 4, 5, 6 или 8 мягких лепестков в зависимости от источника.
- Лепестки строятся кривыми, а не острыми линиями.

### Sunburst / Печати / Зубчатые Стикеры

- Используй только если в источнике реально есть зубчатая печать.
- Количество лучей копируй примерно: 12, 16, 20, 24.
- Если лучи мягкие, используй `stroke-linejoin="round"` или кривые.
- Если лучи острые, можно polygon/path с прямыми сегментами.

### Искры / Sparkles

- Четырехконечная искра обычно имеет вогнутые стороны: строится кривыми `Q`, не ромбом.
- Если источник показывает ромб, делай ромб.
- Если источник показывает sparkle, делай sparkle.

### Волны, Завитки, Стрелки

- Используй SVG `path` с `stroke-linecap="round"`.
- Копируй толщину линии и цвет.
- Не добавляй заливку, если линия в источнике только stroke.

### Линии, Разделители, Рамки

- Копируй стиль: solid, dashed, dotted, double, hand-drawn.
- Копируй толщину: 1px, 2px, 3px.
- Копируй opacity: если линия серая и тонкая, не делай черную.

## Проверка Перед Отчетом

Перед финальным ответом сравни каждую декоративную форму с источником:

- Тип формы совпадает?
- Пропорции совпадают?
- Есть ли лишняя рамка?
- Есть ли лишняя тень?
- Контур слишком острый или слишком мягкий?
- Форма симметрична там, где источник асимметричен?
- Не перенесен ли стиль из прошлой задачи?

Если ответ хотя бы на один пункт плохой, исправь код до отчета.
